# Requirements tracker — 0.5 pilot

This is the implementation contract for continued work, not a declaration that the brief is complete. Read `validation.md` for evidence, `build-status.md` for shipped scope and `autonomous-roadmap.md` for the next development task.

| Requirement / concern | Current state | Remaining acceptance evidence |
| --- | --- | --- |

| Demo and public source | Public repository and pilot emulator walkthroughs | Final submission demonstration on actual supported Android phones, including two AR modules and trainer/QR workflow |
| Deployment | Local dashboard build and preview work | Resolve original uncertain Sites registration; no duplicate registration, fabricated site ID or unrelated server deployment |

Do not present profile selection as authentication, signature authenticity as current certification, visual realism as physical competence, or emulator success as real camera validation. These are independent requirements with independent evidence.
